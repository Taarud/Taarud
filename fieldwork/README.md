# Fieldwork research intelligence feed

This branch hosts a public **agency-policy research feed** for Fieldwork Scout. It is separate from the repository's default branch.

- Live feed: `fieldwork/research-feed.json`
- Direct URL: https://raw.githubusercontent.com/Taarud/Taarud/fieldwork-research-feed/fieldwork/research-feed.json
- Feed updates must use a newer `YYYY-MM-DD.N` version, official HTTPS policy sources and an evidence review.
- Never publish names or details of private users, requester email addresses, request correspondence, fees personally paid, incident/case records, or service credentials.
- A records-request route is not a license to publish or monetize bodycam footage. Legal access, fees, and commercial reuse must be assessed separately.
- Fieldwork automatically preserves existing legal blocks and does not accept commercial-reuse clearance from feed records.
- New research is **not** published by an ordinary ChatGPT response: an editor must update the file here, for example through an authorized GitHub connection. The extension checks for updates daily while Chrome runs.
